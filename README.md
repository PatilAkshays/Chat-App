# Chat App

A native iOS Chat Application built using Swift and SwiftUI.

## Features

- User authentication
- One-to-one chat
- Real-time messaging
- Message history
- Push notifications
- MVVM-C architecture
- Swift Concurrency
- REST API integration

## Tech Stack

- Swift
- SwiftUI
- Swift Concurrency
- MVVM-C
- URLSession
- GitHub Actions
- Fastlane
